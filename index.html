Community funding

These tools live because the community supports them

Custom domains, hosting, API services, maintenance, and ongoing development are not free. Finished and unfinished tools alike depend on donations. Use the tools, report bugs, share them, or fund what you find valuable — that is how BCHtools stays online for the ecosystem.

What support covers

  • Custom domains — bchtools.cash and tool-specific domains
  • Hosting — Vercel / static deploys so tools stay reachable
  • API proxies — serverless routes so browsers can reach BCH data sources
  • Maintenance — broken endpoints, dependency updates, monitoring
  • Development — finishing beta tools and fixing what the community flags

Without support

  • Domains expire and links break
  • API proxies go offline → tools stop loading live data
  • Unfinished tools never get the next round of work
  • Finished tools slowly rot as sources change

Rough ongoing cost is low in absolute terms, but it is recurring. Community BCH is what keeps everything free and public.

The toolkit

All tools

Finished, beta, and unfinished — filter by status, category, or search. Use “I use this”, send feedback, or share a tool you care about.

Unfinished & beta tools

These are not abandoned. They wait for the community to show they are worth continuing — through use, feedback, or funding.

Your move decides what lives. Use one tool, report one bug, share one link, or fund one domain. That is participation. Without signals, unfinished tools stay unfinished and finished ones slowly rot.

Building is only part of the work. Keeping tools alive requires hosting, domains, APIs, development time, fixing broken sources, and new features.
