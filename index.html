What this is

A community-supported home for independent Bitcoin Cash tools

These tools are free to use. Keeping them alive isn’t free.

Domains expire. Hosting costs money. APIs sometimes need to be paid for. Dependencies need maintenance. Bugs need fixing. New features require development time. Community support helps make all of this possible.

      About

      Built independently. Supported by people who want these tools to keep existing.

      BCHtools is a collection of independent software for the Bitcoin Cash ecosystem. It is not a company product, not a charity site, and not a personal portfolio alone — it is a practical toolkit that depends on community support to stay online, maintained and improved.

      Most tools are open source. This site is too. Fork it, fix copy, add a tool. Inspect the code, criticize it, suggest improvements.
